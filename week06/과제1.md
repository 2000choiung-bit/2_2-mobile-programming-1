대로 출력이 되는지 코드를 실행하여 확인(실행결과 캡처하여 제출)하시오. val x = 1
fun foo(y:Int) {
fun bar(x: Int) {
println(y)
println(x)
}
println(x)
bar(10)
}
fun bar(x:Int) {
var x = x
x = x - 1
println(x)
}
fun main() {
bar(x)
foo(x+10)
}
예상 답 : main()이 실행되면 먼저 bar(x)를 부름, main안에 bar(x)가 없으니 위로 올라가서
fun bar(x:Int)를보면 제일 위에 선언된 x=1을 가져와서 x=x-1이니까 x=0 println(x) = 0
다음 foo(x+10)인데 다시 bar(x)를 실행하니까 x=0 foo()안에 bar()는 0,0 그아래 x도 0 먼저
나오고 bar(10)이니까 아무일없어 보임. 최종 답: 0,0,0,0
실제 실행결과 :

1
11
10
해설: foo(x+10)할 때 맨위 x=1이 그대로와서 foo(11)인데 foo안에 bar는 먼저실행되는 것이
아닌 선언만 한 상태로 아래로 넘어감 그래서 println(x)먼저 실행 x=1 , 그후 bar(10)을 지
금 호출됨 그래서 순서대로 11,10이 호출됨
2) 0보다 큰 10진수 숫자를 입력받아서 홀수인지를 Boolean 로 반환(홀수이면 true)하는 함
수를 작성하라. 함수의 선언타입은 다음과 같으며 구현시 반드시 when을 사용해야 한다.
fun isOdd(n: Int): Boolean {
 return when (n % 2) {
 1 -> true
 else -> false
 }
}
3) 다음 클래스 정의를 보고 UML 클래스 다이어그램으로 그린 다음, 각 title이 어떤 title을
가리키는지 설명하라. class Foo(title: String) {
val title = "$title!"
var title2: String
fun printTitles() {
println(title)
println(title2)
}
init {
title2 = title
}
}
(1) UML 클래스 다이어그램
+-----------------------------------+
| Foo |
+-----------------------------------+
| - title: String |
| - title2: String |
+-----------------------------------+
| + Foo(title: String) |
| + printTitles(): void |
+-----------------------------------+
(2) 각 title이 어떤 title을 가리키는지
class Foo(title: String)title: • 생성자의 매개변수 입니다. • 객체 생성 시 전달되는 초기 문자열 값입니다. val title = "$title!": • 좌변의 title: Foo클래스의 멤버 프로퍼티(Property)입니다. • 우변 문자열 내 $title: 위 생성자 매개변수 title을 참조합니다. 전달받은 값 뒤에 !
를 붙여 멤버 프로퍼티 title에 저장합니다. println(title): • 멤버 프로퍼티 title("$title!"형태)을 참조하여 출력합니다.
init { title2 = title }내의 title: • 초기화 블록에서 title을 참조할 때는 생성자 매개변수 또는 멤버 프로퍼티를 가리키
는데, 이 경우 멤버 프로퍼티 title의 값을 title2에 할당합니다.
