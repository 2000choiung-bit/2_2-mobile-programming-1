# 📱 모바일 프로그래밍(1)

부천대학교 컴퓨터소프트웨어과 **모바일 프로그래밍(1)** 수업 내용 및 주차별 과제 정리 저장소입니다.

## 📁 주차별 학습 및 과제 목차

| 주차 | 주요 학습 내용 | 과제 / 실습 내용 | 상태 |
| :--- | :--- | :--- | :---: |
| **01주차** | 코틀린 시작하기, AI 활용 기초 | 코틀린 기본 문법, 변수(var, val), 기본 자료형, 함수 선언, 생성형 AI 도구(Gemini, GitHub Copilot) 소개 및 프롬프트 실습 | 완료 |
| **02주차** | 조건문과 객체 지향 이해하기 | Conditional(if, when) 표현식, Class와 Object 정의, 객체 생성, 속성(Property) 및 메서드(Method) 예제 실습 | 완료 |
| **03주차** | Enum과 Null 안전성 이해하기, AI 활용 클래스 작성하기 | Enum Class, Null Safety(Nullable/Non-Nullable Type, Elvis Operator `?:`, `!!`), AI 활용 클래스 설계 및 작성 결과 검토 | 진행 중 |
| **04주차** | 람다와 컬렉션 개념 이해하기 | Lambdas and Function References(람다식, 고차 함수, Closure), Lists(생성, 요소 추가/삭제, 순회) 예제 실습 | 대기 |
| **05주차** | 셋, 맵의 특징 이해하기 | Sets(기초 및 활용), Maps(생성 및 연산), Collection Functions(filter, map, forEach 등) 실습 | 대기 |
| **06주차** | 확장과 AI 활용 스코프 개념 이해하기 | Receivers and Extensions(수신자 및 확장 함수, 확장 프로퍼티), Scopes 및 생성형 AI 활용 스코프 함수 비교 분석 | 대기 |
| **07주차** | 스코프와 인터페이스 개념 이해하기 | Scope Functions(let, run, with, apply), Interfaces(서브타입/슈퍼타입, 캐스팅, 다중 인터페이스, 상속) 실습 | 대기 |
| **08주차** | **중간고사** | 1주차부터 7주차까지 학습한 코틀린 기초 및 객체 지향 개념, 컬렉션, 인터페이스 등 종합 평가 | 대기 |
| **09주차** | 위임과 추상 클래스 개념 이해하기, AI 활용 클래스 상속 설계하기 | Class Delegation(by 키워드 활용 위임), Abstract Class(추상 클래스), AI 활용 SOLID 관점 설계 검토 및 보완 | 대기 |
| **10주차** | Open Class와 Data Class 개념 이해하기, AI 활용 구조 분해 이해하기 | Open Classes(open 키워드), Data Classes and Destructuring(Overriding `equals`, `toString`, 구조 분해 매핑) 실습 | 대기 |
| **11주차** | Sealed 개념과 예외 처리 개념 이해하기 | Sealed Types(Sealed 타입과 클래스), Handling Runtime Exceptions(1): 예외 발생 상황 및 코드 작성 실습 | 대기 |
| **12주차** | 예외 처리와 제네릭 개념 이해하기 | Handling Runtime Exceptions(2): try-catch-finally 문, Throwing Exceptions, Generics(제네릭 타입, 타입 파라미터 제약) 실습 | 대기 |
| **13주차** | 공변성과 비동기 개념 이해하기 | Generic Variance(Invariance, Covariance `out`, Contravariance `in`), Coroutine(코루틴 소개 및 in/out 기본 코드) 실습 | 대기 |
| **14주차** | 코루틴 기초 이해하기 | Coroutine Context, Dispatchers, Cancellations 예제 작성 및 전체 종합 학습 정리 | 대기 |
| **15주차** | **기말고사** | 9주차부터 14주차까지 학습한 Class Delegation, Data Classes, Exceptions, Generics, Coroutine 등 종합 평가 | 대기 |
